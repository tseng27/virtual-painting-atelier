## 已知問題

- 水彩與水墨的擴散、邊緣積色在收筆時計算，繪製中看到的是預覽，收筆瞬間會有輕微變化。
- 大尺寸畫布（A3、自訂 4096px）在低階裝置上，水彩收筆與油畫取色可能出現短暫延遲；尚未做 Web Worker／WebGL 加速。
- 3D 畫室在無 GPU 的環境以軟體算繪時較慢；觸控或 4 核以下裝置會自動啟用輕量模式，也可切換為靜態畫室。
- 影片匯出依賴 MediaRecorder，以即時速度錄製（10–40 秒），錄製期間需保持分頁在前景。
- 歷史紀錄的復原範圍限於本次開啟後的操作；重新開啟的作品不能復原到上次工作階段之前（筆觸資料仍完整保留以供回放）。
- 混色為 RGB 近似，非顏料光學模型。

## 後續最值得擴充

2. 筆觸運算移至 Web Worker + OffscreenCanvas，提升大畫布效能。
3. 選取、變形、圖層混合模式與參考圖片。
4. Kubelka–Munk 混色模型與實體調色盤混色區。
5. 回放加入鏡頭跟隨與音樂，並支援匯出 GIF。
6. 選用的雲端同步（需帳號系統，與目前免登入設計分開）。
